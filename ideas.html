Make agents prove outcomes, not narrate successstrongest

Hallie recommends converting intent into intermediate checks and enforcing essential verification in hooks and CI, rather than trusting a persuasive completion message. At Duolingo, Agrawal describes restricting generated test changes, automated review and human approval; coverage gains were reported by the team and do not by themselves prove fewer defects. Robinhood combines deterministic checks with an agent looking for contextual risks beyond those checks, while retaining people for sensitive or uncertain decisions.

  • Rethinking Claude Code Best Practices Lydia Hallie, Anthropic
  • 225,000 Lines of Tests, Written and Merged by Agents Kush Agrawal, Duolingo
  • 60% of Our Data PRs Now Merge With No Human Review Chetas Joshi, Robinhood
Treat delegation as a distributed system with uncertain effectsstrongest

Konda argues that a timeout after a tool call does not establish whether the action happened: track evidence and side effects, bind approval to the action, and read back state before retrying. The UndoBench speakers make the related distinction between safe retry, restoration and compensation, proposing pre-state witnesses and tested recovery plans. These are proposed engineering approaches and benchmark findings, not guarantees that every external action can be reversed.

  • Your Sub-Agents Are a Distributed System. Treat Them Like One. Girish Konda, Microsoft
  • Your Coding Agent Can't Undo Its Own Mistakes Tanmay Sah & Dolly Sah
Evaluate the evaluator—and hold out real variationsstrongest

LinkedIn’s Gandhi and Guo found that their judge confused some weak outputs and that a reflection system could misattribute errors; they improved rubrics with human review before using feedback to optimize prompts. Ramp’s Stevens describes replayable bookkeeping worlds and skill ablations, while Kanazawa found his agent-written rubric had overfit one lecture and needed testing on other videos. These are different evaluation settings, but each shows why a good-looking score or a single successful example is not enough.

  • An Agent That Fixes Its Own Mistakes Saloni Gandhi & Ziwei Guo, LinkedIn
  • How Ramp Tests Its AI Bookkeeping Agent Before Customers Do Ryan Stevens, Ramp
  • I Let Agents Refactor My Codebase for 3 Weeks. Then I Read the Code. Keiji Kanazawa, Microsoft
Isolation protects execution, not permission to cause harm

Hallie distinguishes deny rules from sandboxing: an approved command can still run child code, and her described shell sandbox does not cover every agent component. A disposable machine also cannot undo a pushed commit or a sent message; Ivanda similarly warns that tools invoked outside an embedded runtime can retain host privileges, although his separate-machine recommendation comes from a sandbox vendor. Ben Chaim’s skill-testing work adds that dynamic tests only observe the routes exercised, so a clean run is not proof of safety.

  • Rethinking Claude Code Best Practices Lydia Hallie, Anthropic
  • The One Thing Every AI Agent Framework Agrees On Mislav Ivanda, Daytona
  • You Can't Tell What an Agent Skill Will Do by Reading It Roey Ben Chaim, Zenity
More parallel agents move the bottleneck to shared capacity and merge

Harvey’s Wang reports that duplicate alerts spawned redundant work and that a large burst of CLI tasks blocked colleagues, motivating deduplication and a fair launch queue; he says merge scaling remains unsolved. Uber’s speakers describe a different tradeoff: relaxing some pre-merge conflict checks for throughput, then maintaining a separately validated main pointer. That improves reported throughput at the cost of allowing some untested combinations onto raw main, with the reliability cost unquantified in the talk.

  • The Agents Were Fine. Everything Around Them Broke. Joey Wang, Harvey
  • AI Writes Code Faster Than Uber Can Merge It Preetam Dwivedi & Manjari Akella, Uber
Preserve corrections as testable context, not an ever-growing prompt

Linear’s Moor describes enriching issues with prior decisions and extracting lessons from feedback and reverts, while warning against enormous instruction files. Douglas suggests capturing agent sessions and review corrections, then starting with reusable skills and evaluations rather than assuming post-training is necessary. Petrov adds a way to test whether a skill contributes: compare defined tasks with and without it, and keep deletions only if task performance survives; what a model already knows varies with the model and the grading standard.

  • What Your Coding Agent Can't See in the Code Tom Moor, Linear
  • Every Correction You Give Your Agent Is Data Brian Douglas, Paper Compute
  • Your SKILL.md Is 70% Stuff the Model Already Knows Nikolay Petrov, Intel
Trace financial conclusions to assumptions and source versions

In the Costco forecasting exercise, the Together AI speakers found an unsupported membership assumption and an incorrect geographic scope whose errors partly cancelled, making a close forecast misleading. Fieldguide’s Veeraragavan argues that consequential audit conclusions also need stable evidence identity and version, recorded decision steps, and protection for work a human has already reviewed. His reconciliation example is fictional, and these controls are an assurance design—not proof of regulatory compliance.

  • Right Answer, Wrong Reasons: AI Forecasts Costco Hassan El Mghari & Omar El Mghari, Together AI
  • Your Financial Agent Needs to Show Its Work Anirudh Veeraragavan, Fieldguide
Catch ambiguity before an agent faithfully builds the wrong thing

AWS’s Kotyal proposes translating requirements into formal constraints to expose conflicts, gaps and alternative interpretations before implementation. A solver checks the constraints it receives, not whether the translation reflects the owner’s intent, so unresolved interpretations still need domain judgment. In a separate workshop, Monzo’s presenters similarly put clarification and explicit assumptions ahead of reusable calculations; their example is illustrative, not a production benchmark.

  • Your Spec Has Bugs. Catch Them Before Your Agent Codes. Rajath Mahendrappa Kotyal, AWS
  • Stop Chatting With Spreadsheets Francesco Galletta & Felippe Felisola Caso, Monzo
